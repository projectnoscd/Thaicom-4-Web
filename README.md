# THAICOM 4
ใช้ Node.js 20.19 ขึ้นไป

หากต้องการ HTML ที่มีข้อมูลติดไปด้วย ให้รัน `npm run export:html`
แล้วเปิดหรือส่งไฟล์ `thaicom-with-data.html` ได้โดยไม่ต้องเปิด backend
ข้อมูลเป็นชุด ณ เวลา export หากต้องการข้อมูลใหม่ให้ export อีกครั้ง
ทั้ง `index.html` และ `thaicom-with-data.html` มีข้อมูล รูป และไลบรารีติดไปด้วยหลัง export
เปิดไฟล์โดยตรงจะใช้ข้อมูลที่แนบไว้ ส่วนการเปิดผ่าน backend จะโหลดข้อมูลสดตามเดิม

กราฟ TLE ใช้วันที่จาก `Date.txt` และค่าจาก `TLE.txt` ใน document เดียวกัน
แสดง 10 วันล่าสุด โดยใช้ document ล่าสุดหากมีวันที่ซ้ำ และข้ามรายการที่วันที่หรือ TLE ไม่ถูกต้อง

1. รัน `npm start`

เปิดเว็บได้ทั้ง http://localhost:3002 และดับเบิลคลิก `index.html`
เมื่อเปิดไฟล์ HTML โดยตรง จะดึงข้อมูลจาก backend ที่ http://localhost:3002
ต้องเปิด backend ไว้และตั้งค่า MongoDB ใน `.env` ให้ถูกต้อง
หากตั้ง `CORS_ORIGINS` เอง ให้เพิ่ม `null` เพื่ออนุญาตการเปิดจากไฟล์ HTML


หน้า HTML จะโหลดข้อมูลล่าสุดเมื่อเปิด และตรวจข้อมูลซ้ำทุก 30 วินาที
พร้อมรับการแจ้งเตือนเมื่อมีการเพิ่ม แก้ไข หรือลบข้อมูลใน MongoDB
เมื่อกลับมาที่แท็บหรืออินเทอร์เน็ตเชื่อมต่อใหม่ จะโหลดข้อมูลให้อีกครั้ง

หากเปิด HTML จากเครื่องอื่น ให้ระบุ backend ที่เข้าถึงได้ผ่าน `?api=` เช่น
`file:///C:/Thaicom/index.html?api=https://tracking.example.com`
โดยเปลี่ยน URL ตัวอย่างเป็น backend ที่รัน `server.js` จริง
หากไม่ระบุ จะใช้ `http://localhost:3002` ซึ่งต้องรัน backend บนเครื่องที่เปิดไฟล์
ไฟล์ HTML เพียงอย่างเดียวไม่สามารถเชื่อม MongoDB ได้โดยตรง
